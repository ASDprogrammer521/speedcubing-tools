A clean, fast, and good-looking speedcubing dashboard built for practice.

**Live demo:** *https://speedcubing-tools.netlify.app*

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| ⏱️ **Smart Timer** | Spacebar control, inspection timer, scramble generator |
| 🧩 **2×2 → 7×7** | Full multi-puzzle support with proper scramble lengths |
| 📊 **Session Stats** | Best, Worst, Mean, ao5, ao12 + full time history |
| 🧠 **CFOP Trainer** | 57 OLL + 21 PLL + basic F2L algorithms |
| ⚡ **Practice Mode** | Random cases, hide/show algs, drill until muscle memory |
| 🌌 **Cyber UI** | Dark theme, neon accents, animated particle background |

---

## 🚀 Quick Start

1. Open `speedcubing-tools.html` in any modern browser  
   **or**
2. Host it with GitHub Pages / Netlify / Vercel

No install. No dependencies. Just open and solve.

---

## 🎮 How to use the Timer

| Action | Key |
|--------|-----|
| Ready | Hold `Space` |
| Start | Release `Space` |
| Stop | Press `Space` |
| New scramble | Click button or auto after solve |

Inspection can be toggled ON/OFF.

---

## 📚 Algorithm Trainer

- **OLL** — all 57 cases  
- **PLL** — all 21 cases  
- **F2L** — common basic inserts  

Enter **Practice Mode** to get random cases. Hide the algorithm and reconstruct from memory.
